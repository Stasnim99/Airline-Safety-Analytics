US Aviation Safety Analytics

Eighteen years of US civil aviation accidents, built directly from the NTSB Aviation Accident Database (2008 through 2025).

Source: NTSB Aviation Accident Database. All figures below are computed offline from the raw database, not fetched live.

Accidents per year

Total reported accidents versus accidents with at least one fatality, by year.

Aircraft category

Which kind of aircraft was involved.

Phase of flight

What the aircraft was doing when the accident sequence began.

Root cause categories

The top level category of every finding NTSB investigators marked as an actual cause (as opposed to a contributing factor), summed across all accidents in the period.

Where accidents happened

Each marker is one accident. Zoom in to break clusters apart. Color shows the highest injury level recorded for that accident.

Wildlife strikes

Planned addition using the FAA Wildlife Strike Database (breakdowns by airport, month, and damage severity). That database sits behind a search form rather than a plain download link, so this section will go live once that export is pulled by hand and run through the same processing pipeline as the NTSB data above. See the project README for the exact steps.

Common contributing factors

Planned addition using de-identified narrative reports from NASA's Aviation Safety Reporting System, summarized as the most frequent contributing factor terms. Also pending a manual export, documented in the README.

Data: NTSB Aviation Accident Database, 2008 through 2025 (the current year is left out of yearly figures since it is still incomplete). Built as a data analytics portfolio project. View source on GitHub.
